    Justificación de la Estimación (Estándar PERT)

    Las estimaciones de esfuerzo (Horas de Diseño y Ejecución) se calculan automáticamente utilizando la Técnica de Estimación de 3 Puntos (PERT).

    Este es un método estándar en la gestión de proyectos, respaldado por el PMBOK© del Project Management Institute (PMI).

    Fórmula Aplicada

    Te = (To + 4Tm + Tp) / 6

    Valores Reales Aplicados (Complejidad: {{ analisis_info.nivel }})
    To (Optimista) {{ "%.2f"|format(analisis_info.pert_to) }} horas/caso
    Tm (Más Probable) {{ "%.2f"|format(analisis_info.pert_tm) }} horas/caso
    Tp (Pesimista) {{ "%.2f"|format(analisis_info.pert_tp) }} horas/caso
    Te (Estimado) {{ "%.3f"|format(analisis_info.tiempo_estimado_por_caso) }} horas/caso

    Cálculo: Te = ({{ "%.2f"|format(analisis_info.pert_to) }} + 4×{{ "%.2f"|format(analisis_info.pert_tm) }} + {{ "%.2f"|format(analisis_info.pert_tp) }}) / 6 = {{ "%.3f"|format(analisis_info.tiempo_estimado_por_caso) }}

    Total: {{ "%.3f"|format(analisis_info.tiempo_estimado_por_caso) }} × {{ analisis_info.casos }} casos = {{ "%.2f"|format(analisis_info.horas_diseño) }} horas

    VariableDescripciónValor Asignado (por Caso)
    To Tiempo Optimista Los valores (To, Tm, Tp) se asignan según la Complejidad (Baja, Media, Alta) detectada por la IA.
    TmTiempo Más Probable
    TpTiempo Pesimista
    Te Tiempo Estimado Resultado de la fórmula PERT.
    Cálculo Final

    Horas Totales = (Te por Caso) × (Nro. Casos Generados)

    Normativa de Generación de Casos

    El número de casos de prueba se calcula usando la siguiente fórmula estándar:

    Casos Totales = (CA × 3) + (CNF × 5)
    Criterio Factor Justificación
    Criterios de Aceptación (CA) ×3 Cada CA requiere al menos 3 casos: camino feliz, error, y borde
    Criterios No Funcionales (CNF) ×5 CNF requieren más casos (performance, seguridad, usabilidad, etc.)
    Cálculo Aplicado

    Casos Base (CA): {{ analisis_info.criterios }} CA × 3 = {{ analisis_info.casos_base }} casos

    Casos No Funcionales (CNF): {{ analisis_info.criterios_no_funcionales }} CNF × 5 = {{ analisis_info.casos_no_funcionales }} casos

    Total Estimado: {{ analisis_info.casos_base }} + {{ analisis_info.casos_no_funcionales }} = {{ analisis_info.casos }} casos
